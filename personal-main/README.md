# AI-Powered Crop Recommender

An AI-powered application that recommends suitable crops for Kenyan farmers based on location, season, and soil characteristics.

## Features

- Crop recommendation based on county, season, and soil color
- Weather-based analysis
- Vendor marketplace for farm inputs
- User authentication
- Detailed crop information and farming guides

## Installation

### Requirements

- Python 3.8+
- pip
- virtualenv (recommended)
